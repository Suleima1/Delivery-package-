Gift and Surprise Delivery Website
Project Description
The Gift and Surprise Delivery Website is a web-based application that allows customers to order gifts and surprises for their friends, family and loved ones.
Project Objectives
•	To make gift ordering easy.
•	To help people send surprises to loved ones.
•	To provide different gift options.
•	To make online ordering convenient.
Website Features
•	Home page
•	About page
•	Available gifts
•	Customer order form
Technologies Used
•	HTML – Website structure.
•	CSS – Website design.
•	JavaScript – Website functionality.
 Available Gifts
•	Birthday gifts
•	Valentine gift
•	Surprise packages
How to use the website 
1.	Open the website.
2.	View available gifts.
3.	Select a gift.
4.	Enter your details.
5.	Provide the delivery address.
6.	Click Place Order
